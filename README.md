# Meu Primeiro Curso de Python

Projeto criado durante minha jornada inicial de aprendizado no Windows usando Cursor AI + UV.

## Funcionalidades Implementadas
- **Classificador Par/Ímpar Interativo:** Loop infinito com validação de entrada e tratamento de erros.
- **Modularidade:** Uso de funções auxiliares (`eh_numero_valido`, `classificar_parity`) para código limpo.
- **Boas Práticas:** Configuração completa de ambiente virtual e versionamento Git/GitHub.

## Como Rodar
1. Instale [UV](https://docs.astral.sh/uv/)
2. Clone este repositório
3. Rode: `uv run python funcoes_par_impar.py`
